# ✦ add your site

welcome to the cansbridge webring.

this is a simple directory of scholar & fellow websites.

---

## who can add

* cansbridge scholars
* cansbridge fellows
* personal sites, portfolios, blogs

(no companies. no spam.)

---

## how to add

### option 1 — msg shernan on discord

msg me on discord @ **shernan**

### option 2 — pull request

1. fork the repo
2. open `app/data/links.json`
3. add your site
4. open a pr

---

## json format

```json
{
  "website": "https://yourdomain.com",
  "firstName": "your",
  "lastName": "name",
  "city": "toronto",
  "region": "on",
  "cohort": "2026"
}
```

required: `website`, `cohort`

---

## rules

* only scholars / fellows
* use your main domain
* keep it personal
* no promo pages
